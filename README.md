# Kidlat-Quiz-App


An engaging, responsive Quiz Application built with React, Vite, and Tailwind CSS that fetches real trivia questions from the Open Trivia Database API
.
Users can select quiz topics, difficulty levels, and number of questions — then answer questions one by one and see their score at the end.

🚀 Features

 Fetches real questions from the Open Trivia Database API
 Lets users choose category, difficulty, and number of questions
 Displays one question at a time with shuffled multiple-choice answers
 Provides instant feedback (correct or incorrect)
Tracks and shows final score + review summary
Handles errors and loading states gracefully
 Built with React Hooks (useState, useEffect)
Styled with Tailwind CSS for responsive design
 Easily deployable on Netlify or Vercel



 This app uses the Open Trivia Database API to fetch quiz questions dynamically.
 The app gracefully handles:

Network or API failures

Empty or invalid API responses

No questions available for selected filters

User-friendly error messages are displayed in such cases.
